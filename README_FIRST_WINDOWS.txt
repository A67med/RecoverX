RECOVERX FOR WINDOWS - QUICK RECOVERY
===================================

1) Read WINDOWS_START_HERE_AR.md for the Arabic instructions.
2) Install Python 3.12 x64 first if it is not on this Windows PC.
3) Double-click SETUP_WINDOWS.cmd (one-time setup; needs Internet).
4) Double-click START_RECOVERX_WINDOWS.cmd or RecoverX desktop shortcut.

Windows image-only release: physical USB/disk acquisition requires a separate disk-imaging tool.
No native .exe build is included; this is the original Streamlit app plus Windows launch scripts.
Source disk is never formatted by RecoverX.

NEW: Choose Recovery strategy inside Quick Recovery (Smart / TSK / PhotoRec / both / CART / rule-v1).
